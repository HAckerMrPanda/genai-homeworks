L12 - Local MCP server

Use AI to create a local MCP server for sessions.json. Run the supplied tester and obtain a real response. You need Python 3.11+ and the AI assistant from L11; internet is needed once, for the first installation of the MCP library. Everything runs on your computer. Worked example: EXAMPLES.html.

Task

1. Open this lesson folder in your AI assistant and send it the whole text of AI_PROMPT_EN.txt. The AI creates server.py beside sessions.json (not inside examples/).

2. On Windows double-click Run Check EN.cmd. The first run creates .venv and installs the MCP library from requirements.txt, then runs the tester check.py. On macOS/Linux run these commands separately:


python3 -m venv .venv

.venv/bin/python -m pip install -r requirements.txt

.venv/bin/python check.py

3. Check the output: tools/list contains get_session; W101 returns start=18:30; W999 returns found=false. Keep the generated JSON report in results/.

4. Change only W101's start in sessions.json to 20:00. Run the same check again. It must return start=20:00 and W999 found=false. Keep the second report. Do not change check.py.

5. Compare the source snapshots and tool results in both reports: the only source change is the start time, and the server did not modify the source file.

If you see ERROR or no [OK], send the exact error to the AI: "Help fix this run. Do not change check.py; explain what failed." Repeat after the fix.

Submit

In genai-homeworks/L12/:

1. server.py and the final sessions.json with start 20:00.

2. Two JSON reports from results/: before and after editing.

3. README.md, 5-8 sentences: the client, the server, the source file and what changed.

Do not submit .venv. The reference server in examples/ is available for comparison; if you used it, say so, and still perform both runs yourself.
