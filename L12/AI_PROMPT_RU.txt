Я прохожу базовый урок про MCP и не умею программировать. В этой папке есть
sessions.json, requirements.txt, готовая проверка check.py и Run Check.cmd.

Помоги создать мой первый MCP-сервер. Создай только server.py рядом с sessions.json.
Проверку check.py и данные sessions.json не меняй.

Требования:
- Python 3.11+, официальный пакет mcp==2.3.0 из requirements.txt.
- Используй from mcp.server import MCPServer и mcp = MCPServer("my-session-directory").
- Зарегистрируй ровно один Tool: get_session(session_id: str) -> dict через @mcp.tool().
- На КАЖДЫЙ вызов читай соседний sessions.json с encoding="utf-8-sig".
  Путь вычисляй от __file__, чтобы сервер не зависел от текущей папки терминала.
- В JSON есть массив sessions. Если id найден, верни {"found": true, "session": запись}.
  Для неизвестного ID верни {"found": false, "session_id": введённый ID,
  "message": "Session not found"}; дату и время не придумывай.
- Доступ только к этому файлу и только для чтения. Не добавляй аргумент пути к файлу,
  изменение данных, отправку сообщений, внешние API или вызовы LLM.
- Запуск: mcp.run(transport="stdio") внутри if __name__ == "__main__".
  Не используй print в сервере: stdout занят протоколом MCP.

После создания объясни простыми словами: кто клиент, кто сервер, где файл;
почему не открывается сайт; как запустить Run Check.cmd и увидеть get_session,
W101 со start=18:30 и W999 с found=false. Затем объясни, как поменять только
start у W101 на 20:00 в sessions.json и повторить проверку.

Если у тебя есть доступ к терминалу, запусти проверку. В отчёте отличай реальный
успешный запуск от предположения. Если ты только отвечаешь в чате, дай полный
server.py и объясни, как сохранить его с этим именем, без добавления .txt.
